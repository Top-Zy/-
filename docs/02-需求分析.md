# 需求分析报告

## 1 引言

### 1.1 编写目的

本文档面向“武陵山区果园管理系统”的毕业设计开发与答辩，用于明确系统的建设背景、用户角色、功能边界、业务规则和非功能要求，为系统设计、编码、测试和验收提供依据。预期读者包括指导教师、答辩评委、项目开发人员和后续维护者。

### 1.2 项目背景

武陵山区是典型的山地农业区，果园多分布于海拔 300—900 米的山坡和谷地，具有“小气候明显、品种多样、成熟期错峰”的特点。随着电商和乡村旅游的发展，果园的客户不再局限于本地收购商，而是扩展到城市消费者、企业团购和研学团队。传统依靠纸笔、微信群和表格的管理方式，已经难以支撑“展示—获客—下单—履约—复购”的完整链路。

本项目以武陵山区六座典型果园为业务原型，设计一个轻量级果园管理系统。系统不追求覆盖大型农业企业的全部业务，而是聚焦中小果园最常用的“果园展示、产品销售、订单履约、采摘预约、客户沟通”五类场景。

### 1.3 名词说明

| 名词 | 说明 |
|---|---|
| 前台 | 面向普通消费者和游客的网站，包括首页、果园、商城、资讯、个人中心等 |
| 后台 | 面向果园管理员和平台运营人员的 console，用于数据维护和业务处理 |
| 果园档案 | 果园的位置、面积、海拔、品种、负责人、种植介绍等基础信息 |
| 产品 | 果园上架销售的鲜果、山货或茶叶，包含价格、规格、库存、销量等 |
| 订单 | 用户一次结算形成的购买记录，包含收货信息、商品快照和状态流转 |
| 采摘预约 | 用户预约到果园参观、采摘的登记记录 |
| 留言 | 用户提交的咨询、团购、售后或合作意向 |
| 演示数据 | 系统首次运行时自动写入的果园、产品、订单、用户等初始数据 |

## 2 调研与分析

### 2.1 调研对象与方法

| 调研对象 | 调研方式 | 关注问题 |
|---|---|---|
| 果园负责人 | 线上访谈、果园走访 | 种植品种、采收周期、销售渠道、订单处理方式 |
| 合作社运营人员 | 访谈 | 产品分级、库存统计、客户来源、售后处理 |
| 城市消费者 | 问卷与聊天访谈 | 产地信息、价格、配送时效、售后保障 |
| 指导教师 | 评审与讨论 | 功能边界、技术难度、文档规范、答辩可展示性 |

### 2.2 现状与痛点

| 环节 | 现状 | 痛点 | 系统对策 |
|---|---|---|---|
| 产地展示 | 靠朋友圈图片和口头介绍 | 信息零散，消费者难以判断真实性 | 果园档案、产品详情、产地溯源页 |
| 产品管理 | 用 Excel 记录价格和库存 | 多平台价格不一致，库存更新滞后 | 后台统一维护产品、价格、库存、状态 |
| 下单 | 微信转账 + 手工登记 | 容易漏单、地址错、对账难 | 购物车、结算页、订单号、订单状态 |
| 订单履约 | 手工记发货状态 | 用户反复询问，售后无依据 | 后台订单状态流转、状态时间线 |
| 采摘预约 | 电话或微信口头预约 | 容易重复、爽约，接待无准备 | 在线预约、后台确认、预约状态 |
| 客户沟通 | 聊天记录分散 | 回复不及时，问题无法沉淀 | 留言板、后台回复、状态标记 |
| 内容运营 | 临时写文案 | 资讯无归档，复购触达弱 | 资讯栏目、草稿/发布、阅读量 |

### 2.3 可行性分析

**技术可行性**：系统采用 HTML5、CSS3、原生 JavaScript 实现，运行在浏览器中，不需要安装客户端；使用 localStorage 模拟数据持久化，零配置即可演示；数据访问层集中封装，后续可替换为 REST API + MySQL。开发工具 VS Code 和 Node.js 均为常用工具，技术风险可控。

**经济可行性**：开发阶段全部使用开源工具和本地资源，无服务器、域名、数据库和第三方服务费用；部署时普通云服务器即可运行，适合中小果园的预算。

**操作可行性**：前台按照消费者熟悉的电商浏览和下单习惯设计；后台采用“左侧导航 + 数据表格 + 弹窗表单”的经典管理界面，管理员经过简单培训即可上手；移动端自适应，果农可直接用手机查看订单。

**进度可行性**：项目分为需求、设计、前台、后台、联调、测试、文档七个阶段，按 12 周安排，每个阶段都有可检查的成果，进度可控。

## 4 功能需求

### 4.1 前台功能

#### 4.1.1 首页

- 展示品牌主视觉、核心数据（合作果园数、在售产品数、注册用户数、累计订单数）；
- 展示推荐果园、推荐产品、品牌故事、最新资讯和采摘预约入口；
- 顶部导航支持首页、合作果园、鲜果商城、果业资讯、关于我们、联系我们；
- 显示购物车数量角标和登录状态；
- 支持移动端抽屉式导航。

#### 4.1.2 合作果园

- 以卡片形式展示果园封面、产区、地址、简介、标签和主栽品种；
- 支持按产区筛选（湘西、张家界、怀化、铜仁、恩施、黔江）；
- 支持按果园名称、村庄、品种、标签搜索；
- 展示合作流程（提交档案、实地品控、上架运营）。

#### 4.1.3 果园详情

- 展示果园大图、产区、地址、海拔、面积、负责人、品种和详细介绍；
- 展示该果园在售产品；
- 提供采摘预约表单：联系人、手机号、到访日期、人数、备注；
- 未登录用户提交预约时引导登录，登录后回到原页面；
- 同一用户在同一果园、同一天只能有一条未取消预约，避免重复提交。

#### 4.1.4 鲜果商城

- 以卡片形式展示产品图片、名称、品类、规格、产地、价格、销量、库存；
- 支持全部/鲜果/山货/茶叶分类筛选；
- 支持按名称、产地、标签搜索；
- 支持综合排序、价格升序、价格降序、销量优先；
- 支持列表页快速加购和详情页加购。

#### 4.1.5 产品详情

- 展示产品大图、缩略图切换、价格、规格、库存、销量、评分；
- 展示产地、所属果园、储存方式、发货说明；
- 支持数量加减、加入购物车、立即购买；
- 提供商品详情、产地与溯源、购买须知三个 Tab；
- 展示同类推荐产品。

#### 4.1.6 购物车与结算

- 购物车按用户隔离，游客购物车在登录后合并到用户购物车；
- 展示商品、单价、数量、小计；
- 支持数量加减、移除商品、金额汇总、运费计算（满 99 元包邮，否则 10 元）；
- 结算页自动填充用户姓名、手机号、地址；
- 校验收货人、手机号、地址和库存；
- 提交订单时生成唯一订单号，扣减库存、增加销量、清空购物车；
- 下单成功页展示订单号、收货信息、金额和状态。

#### 4.1.7 登录与注册

- 支持用户名或手机号登录；
- 注册时校验用户名格式、手机号格式、密码长度、两次密码一致、协议勾选；
- 登录成功后根据角色跳转个人中心或后台；
- 支持记住账号、显示/隐藏密码；
- 登录失败给出明确提示。

#### 4.1.8 个人中心

- 展示头像、姓名、用户名、手机号、注册时间；
- 支持修改姓名、手机号、邮箱、常用收货地址；
- 支持修改密码；
- 订单列表支持按全部/待发货/已发货/已完成/已取消筛选；
- 订单支持查看详情、取消订单、确认收货、再次购买；
- 预约列表支持查看和取消；
- 展示订单数量、预约数量角标。

#### 4.1.9 果业资讯

- 支持全部/平台动态/基地动态/种植知识/活动公告/行业资讯分类；
- 支持标题、摘要、作者搜索；
- 详情页展示封面、作者、发布时间、阅读量、正文、上一篇/下一篇、最近资讯、标签；
- 支持复制文章链接。

#### 4.1.10 联系我们

- 展示客服电话、邮箱、地址、服务时间；
- 提供留言表单：称呼、手机号、邮箱、留言内容；
- 留言成功后进入后台待回复列表；
- 提供常见问题折叠面板和产区分布示意图。

### 4.2 后台功能

#### 4.2.1 管理员登录

- 独立后台登录页；
- 校验账号、密码、角色和账号状态；
- 非管理员账号不得进入后台；
- 登录后进入数据看板，支持退出登录；
- 未登录直接访问后台页面时自动跳转登录页，并记录原页面地址。

#### 4.2.2 数据看板

- KPI 卡片：累计销售额、累计订单、待发货订单、库存预警；
- 经营趋势图：近 6 个月销售额/订单量切换；
- 品类销售占比图：按有效订单商品金额统计；
- 最新订单表：最近 5 笔订单，可查看详情；
- 库存预警：库存 ≤ 100 的产品；
- 热销产品：累计销量前 5 名；
- 待办提醒：待发货、待回复、待确认、库存预警数量。

#### 4.2.3 订单管理

- 按订单号、客户、手机号搜索；
- 按状态筛选；
- 查看订单详情：收货信息、商品明细、金额、支付方式、备注、状态时间线；
- 状态流转：待付款 → 待发货 → 已发货 → 已完成；
- 待付款/待发货订单可取消，取消后恢复库存和销量；
- 分页展示。

#### 4.2.4 产品管理

- 按名称、产地、标签搜索；
- 按品类、状态筛选；
- 新增/编辑产品：名称、品类、价格、单位、库存、规格、所属果园、产地、图片、标签、状态、推荐、描述、详情；
- 上架/下架快捷切换；
- 删除产品（同时从购物车移除）；
- 分页展示。

#### 4.2.5 果园管理

- 按名称、产区、地址、负责人搜索；
- 按产区筛选；
- 新增/编辑果园：名称、产区、地址、面积、海拔、负责人、电话、品种、标签、图片、简介、详情、状态；
- 删除果园时校验该果园下是否仍有产品；
- 展示每个果园的产品数量。

#### 4.2.6 资讯管理

- 按标题、作者搜索，按栏目筛选；
- 新增/编辑资讯：标题、栏目、作者、封面、状态、摘要、正文；
- 支持草稿和已发布两种状态；
- 支持前台预览、删除；
- 记录阅读量。

#### 4.2.7 用户管理

- 按姓名、用户名、手机号搜索；

- 重置普通用户密码为 123456；
- 管理员账号不可停用。

#### 4.2.8 留言管理

- 按姓名、手机号、内容搜索；
- 按待回复/已回复筛选；
- 查看留言详情并回复；
- 回复后状态自动变为已回复，记录回复时间；

#### 4.2.9 预约管理

#### 4.2.10 系统设置

- 维护系统名称、品牌简称、客服电话、手机、邮箱、微信、地址、服务时间、配送说明、顶部公告、备案信息；

## 5 核心业务流程

### 5.1 购物下单流程

1. 游客或用户进入商城，浏览/搜索产品；
2. 点击“加入购物车”，系统校验产品状态和库存，写入购物车；
3. 用户进入购物车，调整数量或移除商品；
4. 点击“去结算”，未登录用户跳转登录页，登录成功后自动返回结算页；
5. 结算页校验收货信息，计算商品金额和运费；
6. 提交订单，系统再次校验库存，扣减库存、增加销量、生成订单和状态日志、清空购物车；
7. 跳转下单成功页，展示订单号；
8. 管理员在后台将订单从“待发货”更新为“已发货”；
9. 用户在个人中心确认收货，订单变为“已完成”；
10. 若订单在待付款/待发货阶段被取消，系统恢复库存和销量。

### 5.2 采摘预约流程

1. 用户进入果园详情页；
2. 填写联系人、手机号、到访日期、人数、备注；
3. 未登录则跳转登录，登录后返回；
4. 系统校验预约信息格式、日期不早于今天、人数 1—20、同日同果园不重复；
5. 预约写入后台，状态为“待确认”；
6. 管理员确认后状态变为“已确认”；
7. 到访完成后管理员标记“已完成”，用户也可在到访前取消。

### 5.3 留言处理流程

1. 游客或用户提交留言；
2. 系统校验称呼、手机号、内容长度；
3. 留言进入后台“待回复”列表；
4. 管理员查看详情并填写回复；
5. 保存后状态变为“已回复”，记录回复时间；
6. 管理员可删除无效留言。

### 5.4 管理员登录与访问控制流程

1. 管理员访问后台任意页面；
2. 页面加载时读取 `session`；
3. 若不存在会话或角色不是管理员，跳转 `admin/login.html`；
4. 登录页校验账号、密码、角色和状态；
5. 校验通过写入会话，跳转原页面或数据看板；
6. 退出登录清除会话。

| 可维护性 | 数据、UI、页面逻辑分层 | store.js / ui.js / front.js / admin.js 分离；统一命名与注释 |
| 安全性 | 防止常见输入错误和脚本注入 | 输入校验、HTML 转义、角色校验；不存储敏感支付信息 |
| 可扩展性 | 可替换存储层、增加模块 | 数据访问层统一导出 API；新增实体只需增加表、页面和路由 |
| 可测试性 | 核心流程可自动化 | 提供 Playwright 端到端测试脚本和 Node.js 数据层测试 |
| 无障碍 | 键盘可操作、语义化结构 | 表单 label、按钮 aria-label、焦点样式、对比度控制 |

## 7 数据需求

系统需要持久化以下数据：

- 用户：账号、密码、姓名、手机号、邮箱、角色、状态、地址；
- 果园：名称、产区、地址、面积、海拔、负责人、电话、品种、标签、图片、简介、详情；
- 产品：名称、品类、价格、单位、规格、库存、销量、产地、图片、标签、所属果园、状态；
- 订单：订单号、用户、收货信息、商品快照、金额、状态、支付方式、备注、状态日志；
- 资讯：标题、栏目、封面、摘要、正文、作者、阅读量、状态；
- 留言：称呼、手机号、邮箱、内容、状态、回复；
- 预约：用户、果园、联系人、手机号、日期、人数、备注、状态；
- 配置：站点名称、联系方式、公告、配送说明等。

数据保留策略：演示版数据保存在浏览器 localStorage，清理浏览器数据或点击“恢复演示数据”会重置；生产版建议每日备份数据库，订单数据长期保留，用户注销时对个人信息进行脱敏处理。

## 8 约束与假设

1. 演示环境不接入真实支付、短信、物流和地图服务，支付状态由系统模拟；
2. 演示版密码以明文保存在 localStorage，仅用于教学演示，生产环境必须使用哈希；
3. 演示版为单浏览器本地数据，无法支持多用户并发和跨设备同步；
4. 假设使用者具备基本的浏览器操作能力，管理员具备基本的数据维护意识；
5. 系统界面以中文为主，暂不提供多语言。

## 9 验收标准

1. 前台 15 个页面、后台 10 个页面均可正常打开，控制台无未处理异常；
2. 游客可完成浏览、搜索、筛选、加购；用户可完成登录、下单、查看订单、取消订单、确认收货；
3. 管理员可完成登录、看板查看、产品/果园/资讯增删改、订单状态更新、留言回复、预约确认、用户启停；
4. 订单创建与取消时库存变化正确，金额计算正确；
5. 桌面端和手机端布局无横向滚动，主要按钮可点击；
6. 任务书、需求分析、系统设计、数据库设计、测试报告、总结文档齐全；
7. 现场演示 8—10 分钟内可完整走通“前台下单 + 后台发货”主线。
