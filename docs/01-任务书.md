## 一、选题背景与意义

武陵山区横跨湖南、湖北、重庆、贵州四省市，山高谷深、气候温润，是猕猴桃、柑橘、梨、李、莓茶等特色农产品的重要产区。近年来，随着乡村振兴战略推进，山区果园逐步从“分散种植”向“合作社 + 农户”的规模化经营转变。但在实际调研中发现，大量中小型果园仍存在以下问题：

1. **信息分散**：果园档案、种植记录、产品规格、订单和客户信息散落在纸笔、微信聊天和 Excel 表格中，查询和交接困难；
2. **产销脱节**：果园不清楚哪些产品受欢迎、库存还能支撑多少订单，消费者也难以了解果子的真实产地和采摘时间；
3. **服务链条不完整**：产品展示、线上下单、采摘预约、售后咨询彼此割裂，缺少统一的前台入口和后台处理流程；
4. **数字化门槛高**：大型农业 SaaS 系统功能复杂、费用较高，不适合学生团队和中小果园快速上手。

本课题拟设计并实现一个面向武陵山区中小果园的轻量级管理系统，采用“前台商城 + 后台管理”的双模块结构，将果园档案、产品上架、订单处理、采摘预约、资讯发布和客户留言整合到同一套系统中。课题意义主要体现在：

- **应用价值**：帮助中小果园以较低成本建立线上展示与销售窗口，提升订单处理和客户服务效率；
- **专业价值**：综合运用 HTML5、CSS3、JavaScript、数据建模、软件测试和项目管理知识，完成一个可运行、可演示、可扩展的完整项目；
- **社会价值**：通过数字化手段讲好武陵山区产地故事，助力特色农产品走出大山。

## 二、设计目标

### （一）总体目标

设计并实现一个基于浏览器运行的多页面网站——“武陵山区果园管理系统”。系统包含前台展示与购物模块、后台管理模块，核心业务闭环完整，界面美观、操作流畅，能够在普通笔记本电脑上直接演示。

### （二）具体目标

1. **功能目标**
   - 前台：首页、合作果园、果园详情、鲜果商城、产品详情、果业资讯、资讯详情、关于我们、联系我们、登录注册、购物车、结算、下单成功、个人中心；
   - 后台：管理员登录、数据看板、订单管理、产品管理、果园管理、采摘预约管理、资讯管理、用户管理、留言管理、系统设置；
   - 核心业务闭环：浏览商品 → 加入购物车 → 登录 → 结算下单 → 后台处理订单 → 用户确认收货；
   - 辅助业务闭环：浏览果园 → 提交采摘预约 → 后台确认；提交留言 → 后台回复。
2. **技术目标**
   - 使用原生 HTML5 + CSS3 + ES6 完成，不依赖前端框架和外部 CDN，保证离线可运行；
   - 采用多页面结构，页面之间通过相对路径跳转，便于使用 VS Code 逐页阅读和修改；
   - 使用 localStorage 模拟数据库持久化，封装统一的数据访问层，便于后续替换为 MySQL；
   - 使用 CSS Grid / Flexbox 完成响应式布局，兼容桌面端和手机端；
   - 使用 Canvas 2D 绘制经营趋势图和品类占比图；
   - 提供 Node.js 零依赖静态服务器和 `start.bat` 一键启动脚本。
3. **文档目标**
   - 完成任务书、需求分析、系统设计、数据库设计、测试报告、总结等文档；
   - 文档中的功能、页面、字段、测试用例与系统实现保持一致；
   - 提供答辩演示稿、常见问题回答和演示检查清单。
4. **答辩目标**
   - 能够现场启动系统，完整演示“前台下单 + 后台处理”的主流程；
   - 能够讲解系统架构、模块划分、数据模型、关键技术和测试过程；
   - 能够说明系统的不足与后续改进方向。

## 三、主要任务与内容

### 任务一：需求调研与分析

- 了解武陵山区果园的经营模式和主要业务流程；
- 走访或访谈果园经营者、消费者和平台运营人员，归纳功能需求；
- 完成用户角色分析、功能需求、非功能需求和可行性分析；
- 绘制业务流程图，明确订单、预约、留言等核心流程。

### 任务二：系统总体设计

- 设计“前台 + 后台”的双模块总体架构；
- 划分表示层、业务逻辑层、数据访问层和数据存储层；
- 设计页面结构、导航结构、公共组件和响应式方案；
- 设计订单状态机、预约状态机和权限控制方案。

### 任务三：数据库设计

- 根据业务实体抽象用户、果园、产品、订单、订单明细、资讯、留言、预约、配置等数据表；
- 设计主键、外键、索引、枚举字段和数据字典；
- 编写 MySQL 8.0 建表脚本 `database/schema.sql`；
- 说明演示版 localStorage 与关系型数据库的字段映射关系。

### 任务四：前台网站开发

- 完成 15 个前台 HTML 页面；
- 实现公共页头、页脚、移动端菜单、Toast、模态框等公共组件；
- 实现果园与产品筛选、搜索、排序、详情展示；
- 实现购物车数量管理、登录合并购物车、结算下单；
- 实现个人中心资料修改、订单查看/取消/确认收货、预约查看/取消；
- 实现资讯列表与详情、留言提交、采摘预约。

### 任务五：后台管理系统开发

- 完成 10 个后台 HTML 页面；
- 实现管理员登录与页面访问控制；
- 实现数据看板、KPI 卡片、Canvas 图表、最新订单、库存预警；
- 实现产品、果园、资讯的增删改查；
- 实现订单状态流转、预约确认、留言回复；
- 实现用户启停、密码重置、站点设置、数据导入导出和演示数据重置。

### 任务六：系统测试与优化

- 编写核心数据层测试和端到端浏览器测试；
- 覆盖登录、购物车、下单、取消订单、预约、留言、后台 CRUD 等主流程；
- 检查页面脚本错误、图片加载、链接完整性和移动端布局；
- 修复测试中发现的缺陷，形成测试报告。

### 任务七：文档撰写与答辩准备

- 撰写需求分析、系统设计、数据库设计、测试报告和总结；
- 制作答辩 PPT 和演示稿；
- 准备演示账号、演示数据、常见问题回答和故障备用方案。

## 四、技术要求

| 类别 | 要求 |
|---|---|
| 开发语言 | HTML5、CSS3、JavaScript（ES6） |
| 页面结构 | 多页面 HTML，公共结构由 JavaScript 组件渲染 |
| 布局 | Flexbox、CSS Grid、媒体查询；适配 1440px 桌面端与 390px 手机端 |
| 数据存储 | localStorage 模拟数据库，统一封装数据访问层；提供 MySQL 8.0 建表脚本 |
| 图表 | Canvas 2D 原生绘制，不引入图表库 |
| 图标与图片 | 本地实景照片配 SVG 图标/地图，不依赖外部图片和 CDN |
| 运行环境 | Node.js 18+（推荐 20/22/24）或 VS Code Live Server |
| 测试 | Node.js 数据层测试 + Playwright / Edge 无头浏览器端到端测试 |
| 代码规范 | 严格模式、语义化标签、统一的命名和注释、输入校验、HTML 转义 |
| 文档格式 | Markdown 源文件 + Word 文档；答辩材料为 PPTX |
